# 목차 터전 이정표 개편 작업계획서

홈 목차의 6부 묶음(갯벌·가마솥·소금기·정미소·볏값·들녘)을 회차가 일어난 곳을 기준으로 한 터전 이정표 4개로 바꾼다. 부 번호와 부 설명, 부별 ‘다 읽음’ 표시를 없애고, 읽음 줄을 프롤로그부터 외전까지 한 줄로 잇는다. 회차 화면 머리에는 ‘12화’처럼 회차 번호만 남긴다. 원고 표기, 원고 파서, 콘텐츠 생성, 홈 목차, 회차 머리, 스타일, 테스트, README를 한 작업으로 묶는다.

- 작성일: 2026년 10월 8일
- 작업 상태: 적용 완료(14장), 푸시와 배포 전
- 결정 근거: [목차 부 구분 개선 시안](https://claude.ai/artifact/QoEa2WQWkKV1Bxfc5q7tGD)의 B안(비공개 캔버스)
- 선행 작업: [4차 피드백 반영 결과](4차_피드백_반영_결과.md)의 커밋
- 대상 독자: 사이트 반영 담당자, 원고 편집자

## 1 배경과 결정

지금 목차는 본편 23화를 여섯 부로 묶고, 부마다 한 단어 이름과 설명 문장, 모두 읽으면 붙는 ‘다 읽음’ 표시를 둔다. 검토 결과 이 구조는 얻는 것보다 잃는 것이 많다.

- **이름과 내용이 맞지 않는다.** 본편 23개 회차 중 부 이름이 회차의 중심인 회차는 8개이고, 7개는 부 이름과 거의 관계가 없다. 6화 「겨울 갯벌의 김 양식」은 ‘갯벌’이 아니라 ‘가마솥’ 부에 있다.
- **화면을 많이 차지한다.** 실서비스를 iPhone 13 크기(390×664)에서 재면 목차 3,298px 중 부 제목 6개가 664px(20%)다. 휴대폰 한 화면 분량이다.
- **번호가 두 겹이다.** 회차 머리가 ‘4부 정미소 · 12화’다. 화 번호가 전체 순번이라 부 번호는 회차를 찾는 데 쓰이지 않는다.
- **읽음 줄이 끊긴다.** 부마다 줄이 새로 시작해 프롤로그와 에필로그·외전까지 여덟 토막이 된다.
- **원고와 어긋난다.** 부 설명이 원고가 아니라 `NovelHome.vue`에 따로 있어서, 6부 설명은 ‘네 아들’인데 21화 제목은 ‘다섯 형제가 뭉쳤다’로 바뀌었다. ‘소금기’는 2화 자염·4화 바다·10화 간척지를 잇는 이름이었으나, 4차 피드백으로 자염이 8화로 옮겨 가면서 그 연결이 끊겼다.

| 부 | 부 이름이 중심 | 한 장면에만 나옴 | 거의 무관 |
| --- | --- | --- | --- |
| 1부 갯벌 | 1화 | 4화(바다 조난) | 2화(학교 대신 밭일), 3화(전쟁과 형의 군번) |
| 2부 가마솥 | 5화 | 7화(멸치잡이), 8화(탈곡팀) | 6화(갯벌 김 양식) |
| 3부 소금기 | 10화 | 9화(이주 결심) | 11화(자녀 교육) |
| 4부 정미소 | 12·13·14화 | 15화(이웃을 감싼 일), 16화(아내의 헌신) | |
| 5부 볏값 | 17·18화 | | 19화(정미소 성장), 20화(아내와의 사별) |
| 6부 들녘 | | 21화(형제 분업), 22화(계약재배) | 23화(로봇·법인 전환) |

괄호는 그 회차의 실제 중심 이야기다.

세 시안 중 B안을 택한다.

- **A안(부 없음)** 은 가장 단순하지만 섬에서 RPC까지 이어지는 삶의 흐름을 목록에서 한눈에 볼 단서가 사라진다.
- **C안(이름 고친 여섯 마디)** 은 책 같은 묶음을 남기지만, 이름이 원고에 대한 해석이라 원고가 바뀌면 지금과 같은 어긋남이 다시 생긴다.
- **B안(터전 이정표)** 은 각 회차 시점 줄의 장소로 묶으므로 이름과 어긋나는 회차가 생기지 않는다. 가족이 ‘안면도 살 때’, ‘정미소 할 때’라고 부르는 방식과도 같다.

## 3 디자인 명세

캔버스 B안의 모양과 크기를 따른다. 색은 모두 기존 CSS 변수를 써서 밝은 화면과 어두운 화면을 따로 정하지 않는다. 글자 크기는 기존 단계 변수에 1px을 더해 시안의 15px·17px을 맞추고, 글자 크기 설정을 바꾸면 함께 커지게 한다. `.story-end`가 같은 방식을 쓴다.

| 요소 | 값 |
| --- | --- |
| 이정표 한 줄 | 최소 높이 52px, 위아래 여백 14px, 회차 줄과 같은 24px 줄 칸과 14px 간격 |
| 연도 | `calc(var(--font-meta) + 0.0625rem)`(기본 15px), 굵게, `--link`, 고정폭 숫자, 오른쪽 여백 6px |
| 장소 | `calc(var(--font-ui) + 0.0625rem)`(기본 17px), 굵게, `--ink`, 줄 높이 1.45. 연도와는 공백 한 칸과 연도의 오른쪽 여백을 합쳐 약 10px 띄운다 |
| 제목 마크업 | `<h3 class="place-heading"><span class="place-year">1977</span> 남양만 간척지</h3>`처럼 연도 뒤 공백을 같은 줄에 둔다. 제목을 flex로 만들거나 연도와 장소를 다른 줄에 쓰면 공백이 사라져 화면 낭독과 테스트 문구가 ‘1977남양만 간척지’가 된다 |
| 마름모 | 한 변 11px, 테두리 2px, 45도 회전, 가로 위치 6.5px(줄의 가운데) |
| 마름모 상태 | 터전 첫 회차가 읽음 또는 읽는 중이면 `--link`로 채운다. 아니면 `--surface` 바탕에 `--field-border` 테두리 |
| 마름모 세로 위치 | 장소 글자 첫 줄의 가운데. `calc(14px + (1.45 * (var(--font-ui) + 0.0625rem) - 11px) / 2)` |
| 이정표 구간의 줄 | 폭 2px, 왼쪽 11px. 바로 앞 회차가 읽음이고 마름모가 채워졌으면 `--link`, 아니면 `--nav-secondary-border` |
| 제목 수준과 낭독 | `h3`(목차 `h2` 아래). 줄과 마름모는 `aria-hidden` |
| 제목 기본값 | 전역 초기화가 `margin-top`만 없애므로 `h3`의 아래 여백과 1.17em 글자 크기가 남는다. `.place-heading`에 `margin: 0`과 위의 장소 글자 크기를 직접 준다. `.chapter-list-heading h2`, `.music-setting h3`과 같은 방식이다 |
| 줄바꿈 | `word-break: keep-all`. 좁은 화면에서 장소가 길면 연도 아래로 내려간다 |

회차 줄의 모양은 그대로 둔다. 읽음 체크, 읽는 중 고리, 안 읽음 점, 읽는 중 회차의 배경이 모두 지금과 같다. 바뀌는 것은 줄의 시작·끝과 앞뒤 색을 정하는 기준이다. 부 안이 아니라 목록 전체의 앞뒤 회차로 정하므로, 줄은 프롤로그 위와 외전 아래에서만 끊긴다.

읽는 중 회차 앞의 구분선을 숨기는 규칙은 바로 앞 요소가 회차일 때만 적용된다. 그래서 부 경계였던 4·5화, 16·17화, 20·21화, 23화·에필로그 사이에도 적용되고, 이정표가 끼는 8·9화, 11·12화, 21·22화 사이에는 적용되지 않는다. 의도한 차이다.

## 4 원고 표기와 파서

### 작업 01 원고의 부 제목을 터전 제목으로 바꾼다

| 지금 | 바뀐 뒤 | 위치 |
| --- | --- | --- |
| `# 1부. 갯벌` | `# 1936. 안면도` | 1화 「어머니의 쇠갈고리」 앞 |
| `# 2부. 가마솥` | 삭제 | 5화 「가마솥 손칼국수」 앞 |
| `# 3부. 소금기` | `# 1977. 남양만 간척지` | 9화 「일곱 가구가 따라나선 길」 앞 |
| `# 4부. 정미소` | `# 1983. 독정 정미소` | 12화 「망해가는 정미소를 사다」 앞 |
| `# 5부. 볏값` | 삭제 | 17화 「떼인 3억」 앞 |
| `# 6부. 들녘` | 삭제 | 21화 「다섯 형제가 뭉쳤다」 앞 |
| 없음 | `# 2003. 독정 RPC` 추가 | 22화 「300만 평의 약속」 앞 |

본문, 시점 줄, 회차 제목은 바꾸지 않는다. 줄번호 대신 회차 제목으로 위치를 찾고, 지운 제목 줄의 빈 줄도 함께 정리한다.

표기 규칙은 `# 연도. 장소`다. 연도는 네 자리 숫자이고 앞 터전보다 커야 한다. 장소는 1~20자로 적는다. 터전 제목 바로 아래에는 회차 제목이 와야 한다.

### 작업 02 파서가 터전 제목을 읽는다

`site/.vitepress/shared/episode-heading.mjs`의 `parseManuscript`를 바꾼다.

- 1단계 제목을 `^(\d{4})[.．:：—–-]\s*(.*)$`로 읽어 `{ year, name, label }`을 만든다. 장소는 `(.*)`로 받아 1~20자인지 따로 검사한다. `(.+)`로 받으면 `# 1936.`처럼 장소가 빈 제목이 길이 오류 대신 형식 오류로 빠진다. `label`은 `1977 남양만 간척지`처럼 연도와 장소를 띄어 쓴 문자열이다.
- 제목이 형식에 맞지 않으면, 제목이 `/^\d+부/`로 시작할 때만 옛 부 표기 안내를 내고 나머지는 형식 안내를 낸다.
- 본편 회차에는 바로 앞 터전을 `place`로 붙인다. 프롤로그·에필로그·외전은 `place: null`이다.
- 반환값을 `{ parts, episodes }`에서 `{ places, episodes }`로 바꾼다.
- `site/.vitepress/shared/episode-heading.d.mts`의 `Part` 타입을 `Place = { year: number; name: string; label: string }`로 바꾼다.

| 상황 | 오류 메시지 |
| --- | --- |
| `# 2부. 가마솥` 같은 옛 부 표기 | 부 제목은 더 쓰지 않습니다. `# 1977. 남양만 간척지`처럼 연도와 장소를 적으세요: (제목) |
| 구분 기호 없음, 연도가 네 자리가 아님 등 그 밖의 형식 오류 | 터전 제목은 `# 1977. 남양만 간척지`처럼 네 자리 연도, 마침표, 장소 순서로 적으세요: (제목) |
| 연도가 앞 터전과 같거나 앞섬 | 터전 연도는 앞 터전보다 뒤여야 합니다: (제목) |
| 장소가 비었거나 20자 초과 | 터전 장소는 1~20자로 적으세요: (제목) |
| 터전 제목 아래 본문 | 터전 제목 아래에는 회차 제목을 넣으세요: (제목) |
| 터전 제목 없이 시작한 본편 회차 | 본편 회차 앞에 터전 제목을 넣으세요: (제목) |
| 회차가 없는 터전 | 비어 있는 터전: (label) |
| 원고 첫머리 | 원고는 터전 또는 회차 제목으로 시작해야 합니다. |

작업 01·02·03은 함께 바꾼다. 파서만 바꾸면 옛 원고를 거절하고, 원고만 바꾸면 옛 파서가 거절한다. 파서와 원고를 바꿔도 콘텐츠 생성이 `structure.parts.length`를 읽는 동안에는 `npm test`의 선행 단계(`prepare:content`)가 멈춘다.

## 5 콘텐츠 생성과 데이터

### 작업 03 콘텐츠 생성과 타입

`scripts/prepare-reader-content.mjs`

- 회차 목록 항목의 `part`를 `place`로 바꾼다.
- 생성하는 회차 페이지 머리에서 `partLabel`을 없앤다.
- `catalog.parts`를 `catalog.places`로 바꾼다.
- 완료 로그를 `4개 터전 · 23개 본편 회차 · …`로 바꾼다.

`site/.vitepress/theme/lib/reader-catalog.ts`

- `Episode.part`를 `Episode.place: Place | null`로, `catalog.parts`를 `catalog.places`로 바꾼다.

콘텐츠를 생성하면 `content/ref_images/episode-map.json`의 원고 해시와 `content/ref_images/catalog.html`의 내장 데이터가 자동으로 바뀐다. 두 파일은 직접 고치지 않고 생성 결과만 검토한다. `site/read/`와 `site/.vitepress/generated/`는 git에서 제외된 생성물이다.

### 기존 데이터와의 호환
