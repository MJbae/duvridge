# 배병희 자서전 4차 피드백 반영 작업계획서

6부 23화 구성과 주요 장면을 유지하면서 4차 가족 피드백의 사실 정정을 반영한다. 본문은 표현 교체를 기본으로 하고, 소금 사업의 연대와 전기 도입 전후의 순서에 필요한 문단만 이동한다. 본문 수정 13개 항목, 삽화 편집 2개 항목, 원고와 사이트의 연결 검수를 한 작업으로 묶는다.

- 작성일: 2026년 10월 8일
- 작업 상태: 원고 13개 항목과 삽화 2개 항목 적용 및 검수 완료
- 완료 기록: [4차 피드백 반영 결과](4차_피드백_반영_결과.md)
- 정정 근거: [4차 피드백](../원자료/4차_피드백.md)
- 수정 원고: [배병희 자서전](../배병희_자서전.md)
- 대상 독자: 원고 편집자, 삽화 편집자, 사이트 반영 담당자

## 1 작업 범위와 편집 원칙

회차 번호와 `{#ep01}`부터 `{#ep23}`까지의 ID, 프롤로그·에필로그·외전 ID를 유지한다. 제목은 21화만 ‘다섯 형제가 뭉쳤다’로 바꾼다. 기존 음악 연결과 회차 주소도 유지한다.

4차 피드백이 직접 정정한 사실은 반영하고, 그 사실이 다른 회차에서 반복되면 해당 표현도 맞춘다. 소금 사업 연료의 종류, 막내의 쇼핑몰·라이브커머스 시작 연도, 어머니의 사망 연도 등은 새로 확정하지 않는다. 감자 침지 원리와 액젓의 어종·숙성 설명은 가족이 실제로 했던 작업과 구분하여, 이번 본문에는 필요한 생활 묘사만 넣는다.

직접 정정과 편집 판단을 구분한다. 소금 사업의 시기·시설, 트럭 이동, 전기 도입 뒤의 야적 문제 등은 피드백의 직접 정정이다. 같은 사실을 다른 회차와 참고 목록에 맞추는 것은 연결 수정이다. 문단의 정확한 배치, 친족 호칭의 관점 표시, 21화 삽화의 인원 보강은 사실 정정을 구현하는 편집 판단이다.

기존 사건의 규모, 농지 면적, 금액, 인수 연도, 동행 가구 수는 이번 피드백이 정정한 범위 밖에서는 유지한다. 대사와 감정 묘사도 사실 정정 때문에 연결이 어긋나는 부분만 손본다. 4화의 목선 조난, 경운기 도입 전 발동기, 정미소의 50마력 발동기처럼 별개의 사건·설비는 그대로 둔다.

아래 줄번호는 작성일 현재 원고 기준이다. 실행할 때는 회차 ID와 인용한 원문을 함께 찾아 수정한다. 문단 이동 뒤에는 줄번호가 바뀌므로 줄번호만으로 교체하지 않는다.

### 작업 01 소금 사업의 연대와 장면 위치

**위치와 근거:** 2화 72~80행, 8화 297행 다음. 배선빈 피드백은 소금 생산 시설을 무쇠솥·철판, 시기를 1970년대 초로 정정한다.

2화의 소금 사업 다섯 문단을 8화의 시간·장소 표시 뒤, ‘수산물과 밭작물을 팔아 모은 돈은’ 문단 앞으로 옮긴다. 실패와 비용 계산의 교훈까지 함께 이동한다. 2화에서는 ‘그래서 어머니는 물때마다 바다로 나섰다’ 다음에 ‘배병희도 또래 아이들처럼 학교에 다니고 싶었다’가 이어지도록 한다.

옮긴 단락의 첫 문장은 다음으로 교체한다.

> 1970년대 초, 배병희의 아버지는 소금을 굽는 일에 뛰어들었다. 바닷가에 무쇠솥과 철판을 걸고 바닷물을 끓여 졸이는 전통 자염(煮鹽) 방식이었다.

나머지 문단에서는 두 곳의 ‘소년’을 삭제한다. 연료가 장작으로 확정된 듯한 표현은 ‘장작불 → 불’, ‘땔나무 → 연료’, ‘장작 값·땔나무 값 → 연료비’로 조정한다. ‘소년 배병희 역시 불 곁에서 나무를 나르며 일손을 보탰다’는 ‘배병희 역시 불 곁에서 일손을 보탰다’로 바꿔 장작 운반의 단정을 덜어낸다.

연료의 중립화는 4차 피드백의 직접 정정이 아니라, 1차 소재 정리의 ‘석탄’과 현재 원고의 ‘장작’이 엇갈리는 데 따른 연결 점검이다. 적용 범위는 이동하는 소금 사업 단락으로 한정한다.

**완료 기준:** 2화가 1940년대 학업·노동 이야기로 이어지고, 소금 사업은 8화에서 1970년대 초의 일로 읽힌다. 소금 사업 주체는 배병희의 아버지로 유지되며, 비용 계산의 교훈은 소금 사업 단락에 붙어 있다.

### 작업 02 대용량 감자 전분의 전통 제조 방식

**위치와 근거:** 5화 184행. 배미경 피드백은 감자의 양이 많아 전통 방식으로 전분을 만들었다고 정정한다.

첫 문장만 다음으로 바꾸고 뒤의 비상 식량·별식 설명은 유지한다.

> 상처가 나 쉬이 무르는 감자는 양이 많아 전통 방식으로 전분을 만들어 말려두었다.

**완료 기준:** ‘강판에 일일이 갈아’가 삭제된다. 가족이 사용한 용기, 침지 기간, 발효·여과 과정은 임의로 추가하지 않는다.

### 작업 03 황석어 액젓의 명칭과 용도

**위치와 근거:** 5화 182행. 배미경 피드백은 젓갈이 아닌 액젓이며, 제조 때 냄새가 조금 나지만 음식에 맛을 더했다고 설명한다.

해당 문단을 다음으로 교체한다.

> 식량을 아끼고 갈무리하는 아내의 손끝은 더욱 빛을 발했다. 장독대에는 황새기(황석어) 액젓을 정성껏 담가 두었다. 만들 때는 냄새가 좀 났지만, 곰삭은 감칠맛으로 밥상에 맛을 더했다.

**완료 기준:** 액젓이라는 명칭, 제조 때의 냄새, 음식의 맛을 더하는 용도가 반영된다. 기존 밥상 장면은 유지한다.

### 작업 04 경운기 도입 이후의 탈곡 동력

**위치와 근거:** 8화 309행. 배선빈 피드백은 경운기 도입 이후 별도 발동기를 없애고 자체 엔진을 이용했다고 정정한다.

해당 문단을 다음으로 교체한다.

> 우마차 탈곡단이 성과를 냈지만, 배병희는 이동 효율을 높이기 위해 10마력 경운기를 도입했다. 경운기에 탈곡기를 싣고 달리자 이동 시간이 절반으로 줄었다. 작업할 때는 경운기 자체 엔진으로 탈곡기를 돌렸다. 작업 반경도 섬 전체로 넓어졌다.

**완료 기준:** 경운기에 별도 발동기를 싣는 서술이 사라진다. 303·305행의 우마차 시절 발동기와 13·14화의 정미소 발동기는 유지한다. 베어링 수리 장면의 대상이나 시기를 새로 정하지 않는다.

### 작업 05 트럭 이주와 오산 큰아버지의 역할

**위치와 근거:** 9화 367·373·377·379행, 10화 411행. 배선빈은 오산 큰아버지의 주도와 트럭 이동을, 배미경은 이삿짐 트럭에 탄 기억을 제시한다. 피드백의 ‘7화인가’는 현재 원고의 9화 이주 장면으로 대응한다.

| 위치 | 수정할 표현 |
| --- | --- |
| 9화 367행 | ‘단출한 세간을 손수 챙겨 달구지에 실었고’를 ‘단출한 세간을 손수 챙겼고’로 바꿔, 확인되지 않은 운반 수단을 덜어낸다. |
| 9화 373행 | 아래 문단으로 교체해 주도자와 트럭 이동을 함께 명시한다. |
| 9화 377행 | ‘짐과 기계를 배에 싣고 바닷길을 건너 북쪽으로 향하는 동안’을 ‘짐과 기계를 실은 트럭을 타고 화성으로 향하는 동안’으로 바꾼다. |
| 9화 379행 | ‘대열의 맨 앞에서 묵묵히 걸음을 옮기는 배병희의 든든한 어깨를 보며’를 ‘배병희에 대한 믿음으로’로 바꾼다. |
| 10화 411행 | ‘안면도에서 배로 싣고 온’을 ‘안면도에서 트럭에 싣고 온’으로 바꾼다. |

373행 교체 문단:

> 1977년 무렵, 마침내 고향을 떠나는 날이 밝았다. 화성으로 이동하는 일은 ‘오산 큰아버지’로 불리던 친족이 주도했다. 안면도 들판에서 함께 땀 흘리며 다루었던 10마력 경운기와 탈곡기, 바인더 같은 농기계와 손때 묻은 살림살이를 이삿짐 트럭에 실었다.

‘오산 큰아버지’는 피드백 제공자의 친족 호칭이므로 배병희의 큰아버지로 새로 단정하지 않는다. 이주 결심·동기는 기존 339~355행에 유지하고, 새 문장은 짐을 옮겨 이동하는 과정의 주도자를 밝힌다.

**완료 기준:** 이주 수단은 트럭으로 통일되고 경운기는 옮겨 간 농기계로 남는다. 오산 친족의 이동 주도와 배병희의 이주 결심·이웃들의 신뢰가 함께 드러난다. 공동 농지 취득이나 공동 경작으로 역할을 확대하지 않는다. 4화의 목선 조난은 그대로 둔다.

### 작업 06 주택과 정미소 지붕 재질

**위치와 근거:** 10화 387행, 11화 423행, 12화 501행, 16화 639행. 정미소의 함석 지붕은 직접 정정이다. 앞의 시멘트 기와 지붕은 ‘정미소 지붕도’라는 이어지는 표현과 본문의 반복된 주택 묘사에 근거해 주택을 가리킨다고 해석한다. 주택 세 곳의 연결 수정은 이 해석에 따라 적용한다.

| 위치 | 교체할 문구 |
| --- | --- |
| 10화 387행 | ‘정부에서 분양받은 열여덟 평 남짓한 슬레이트 주택이었다’ → ‘정부에서 분양받은 열여덟 평 남짓한 시멘트 기와지붕을 얹은 집이었다’ |
| 11화 423행 | ‘열여덟 평 슬레이트 집’ → ‘열여덟 평 집’ |
| 12화 501행 | ‘낡은 슬레이트 지붕은 틈새마다 깨져 비가 샜다’ → ‘낡은 함석 지붕은 곳곳에서 비가 샜다’ |
| 16화 639행 | 작업 09의 시점 수정과 합쳐 ‘열여덟 평 시멘트 기와집’으로 바꾼다. |

**완료 기준:** 본문의 동일 주택과 정미소에 ‘슬레이트’가 남지 않는다. 주택 면적과 비좁은 살림 묘사는 유지한다. 함석 지붕의 녹·부식 원인은 새로 쓰지 않는다.

### 작업 07 전기 도입과 야적 문제의 선후관계

**위치와 근거:** 13화 523~525행, 14화 551·553·563·565행, 18화 733행. 배선빈 피드백은 야적 보관의 한계가 전기 도입 이후의 일이라고 정정한다.

회차 번호와 야적 장면은 유지하고 아래 순서로 수정한다.

1. 13화 523행의 농가 유입 문단은 유지한다. 다음 문단 첫머리에 시점을 표시해 525행 문단을 다음처럼 바꾼다.

   > 야적 보관의 한계가 드러난 것은 정미소에 전기를 들인 뒤였다. 당시 정미소에는 쏟아져 들어오는 곡식을 다 들여놓을 만한 번듯한 창고가 없었다.

2. 14화 551행의 창고·진입로 문단 한 개를 563행 전동화 효과 문단 뒤, 565행 상업 도정 전환 문단 앞으로 이동한다. 전기 도입 뒤라는 정정을 반영하면서 창고가 상업 도정·판로 확장보다 앞에 있던 기존 배치는 유지한다.
3. 14화 553행 첫 문장을 다음으로 바꾼다. 뒤의 발동기·장축·벨트 설명은 유지한다.

   > 야적 보관의 한계가 드러나기 전, 배병희는 정미소의 동력 설비부터 바꾸어야 했다.

4. 18화 733행의 투자 요약을 다음 순서로 맞춘다.

   > 1983년 낡은 정미소를 인수할 때 논 일부를 팔았다. 들판에 전봇대를 세워 삼상 전력을 끌어들이느라 땅을 거듭 처분했다. 볏가마를 들일 창고를 짓고 진입로를 닦느라 또 팔았다.

13화는 전기 도입 뒤의 야적 문제를 보여주고, 14화는 ‘야적 보관의 한계가 드러나기 전’으로 전동화 과정을 돌아본 뒤 창고 마련으로 이어진다. 실제 사건의 선후는 ‘전기 도입 → 야적 보관의 한계 → 창고 마련’로 읽혀야 한다. 상업 도정·판로 확장의 시기를 피드백의 새 확정 사항으로 다루지 않는다.

**완료 기준:** ‘창고를 마련한 뒤 전기를 들였다’는 연결이 사라진다. 전기가 농가 유입의 직접 원인이었다는 설명이나 정확한 공사 연도는 추가하지 않는다. 이미 전동화·창고 순서인 17화 671행과 후대의 저장 부족을 다룬 19화 781행은 유지한다.

### 작업 08 흑백 TV와 정미소 전화의 시점 분리

**위치와 근거:** 15화 605~609행. 배선빈 피드백은 흑백 TV 장면을 1970년대 초 안면도의 일로 정정한다.

605행 문단을 다음으로 바꾼다.

> 기계 문물에 밝았던 그는 안면도에 살던 1970년대 초, 집에 흑백 텔레비전을 남보다 앞서 들여놓았다.

607행의 이웃들이 TV를 보러 모이는 장면은 유지한다. 609행 문단은 다음으로 교체한다.

> 훗날 독정리에서는 정미소와 집에 전화기를 남보다 앞서 들여놓았다. 전화기는 농가들과 도정 날짜를 맞추고 서울·인천의 거래처와 연락하는 생명선이었다. 배병희는 자녀들에게 전화 예절만큼은 유독 엄격하게 가르쳤다.

**완료 기준:** TV의 연대·장소가 명시되고 전화 예절은 독정리 이야기로 이어진다. 전화의 설치 장소와 남보다 앞서 도입했다는 기존 정보가 보존된다. ‘전화조차 귀하던 1980년대 초반이었다’는 기존 문장은 삭제한다. 전화 도입 연도를 새로 정하지 않는다.

### 작업 09 정미소 시작 전의 시어머니 봉양

**위치와 근거:** 16화 639~643행. 배선빈 피드백은 할머니를 모시던 시절이 정미소를 시작하기 전이라고 정정한다. 본문에서는 배병희의 어머니이자 아내의 시어머니를 가리킨다.

16화 639행의 첫 문장을 다음으로 바꾸고, 같은 문단의 봉양·병구완 묘사는 유지한다.

> 정미소를 시작하기 전, 독정리의 열여덟 평 시멘트 기와집은 식솔들로 늘 비좁았다.

641행의 이웃 어르신과 일곱 남매 돌봄은 유지한다. 643행 ‘정미소 기계가 본격적으로 돌아가기 시작하자’가 이후 시기로 돌아오는 연결을 맡는다.

12화 489행의 ‘노모를 모시는 가장’은 유지한다. 해당 문장은 499행의 실제 인수보다 앞선 고민 장면이므로 ‘정미소 하기 전 봉양’과 반드시 충돌하지 않는다.

**완료 기준:** 병구완이 정미소 운영 중의 일로 읽히지 않는다. 12화의 인수 전 가족 책임 묘사는 보존하고, 어머니가 인수 전에 돌아가셨다는 사실이나 사망 연도는 추가하지 않는다.

### 작업 10 쌀을 실은 상태의 트럭 도난

**위치와 근거:** 17화 705행. 배선빈 피드백은 납품 완료 뒤가 아니라 쌀이 실려 있던 상태에서 도난당했다고 정정한다.

해당 문단만 다음으로 교체한다.

> 쌀이 실린 트럭을 길가에 세워두고 주린 배를 채우려 식당에서 늦은 밥 한술을 뜨고 나왔다. 그 짧은 사이, 쌀을 실은 화물 트럭이 감쪽같이 사라진 것이다.

**완료 기준:** 도난 당시 적재 상태가 분명하다. 창고 침입 도난과 서울 식당 앞 도난은 서로 다른 사건으로 유지하며, 기존 피해 금액과 트럭 대수는 바꾸지 않는다. 프롤로그의 배달 트럭 도난 서술은 이 정정과 충돌하지 않으므로 유지한다.

### 작업 11 서산 농지 매입 동기

**위치와 근거:** 19화 775행. 배선빈 피드백은 원료 벼 확보가 아니라 정미소 운영 과정에서 팔린 논 면적을 다시 확보하기 위한 투자라고 정정한다.

해당 문단을 다음으로 교체한다.

> 정미소를 지키기 위해 독정리의 농토는 1만 2천 평만 남겨두었지만, 배병희는 물러서지 않았다. 정미소를 운영하며 처분했던 논 면적을 다시 확보하려고 충남 서산의 간척 농지 약 3만 평을 새로 사들였다.

**완료 기준:** 매입 동기는 농지 면적의 회복으로 읽힌다. 777행의 자경지가 정미소를 뒷받침했다는 결과 설명은 유지한다. 거래 연도, 가격, 매입 자금 출처는 추가하지 않는다.

### 작업 12 다섯 형제와 막내의 유통 역할

### 작업 13 한국농수산대학교 총장상 명시

**완료 기준:** 학교명과 수상자가 명확하다. 867행의 입학 이야기와 871행의 아버지 배병희가 느낀 보람은 유지한다. 당시 학교 명칭을 따로 정리하는 작업은 이번 수정에 추가하지 않는다.

### 작업 14 9화 이주 삽화의 트럭 정정

현재 [9화 대표 삽화](../site/public/images/episodes/ep09-01-720.jpg)는 경운기가 이삿짐을 운반하는 장면이다. 1977년 무렵 안면도에서 화성으로 이삿짐 트럭을 타고 이동하는 장면으로 편집한다. 인물의 모습과 수채화 화풍을 유지하고, 옮겨 간 농기계를 그릴 경우 트럭에 실린 짐으로 표현한다. 구체적인 트럭 브랜드, 번호판, 이동 경로는 새로 정하지 않는다.

- 공개 이미지 ID와 회차 연결: `ep09-01`, `ep09`, `position.start: true` 유지
- 기존 제작 원본: `content/illustration-sources/ep09-02.png`
- 주의할 다른 원본: `content/illustration-sources/ep09-01.png`는 현재 8화 바인더 삽화 `ep08-03`의 원본이므로 수정하지 않는다.
- 대체 설명: ‘수채화로 그린 이삿짐 트럭을 타고 안면도에서 화성으로 향하는 가족과 이웃들’

**완료 기준:** 경운기가 이주 차량으로 보이지 않는다. 본문과 그림의 운반 수단이 트럭으로 일치하며 8화 바인더 그림은 유지된다.

### 작업 15 21화 대표 삽화의 다섯 형제 보강

21화 삽화의 인원 보강은 가족의 직접 그림 정정이 아니라, 다섯 형제라는 제목·내용과 맞추기 위한 편집 연동이다.

현재 [21화 대표 삽화](../site/public/images/episodes/ep21-01-720.jpg)는 백발의 아버지와 아들 네 명으로 구성되어 있다. 같은 구도와 화풍을 유지하며 아들 한 명을 보강해 아버지와 다섯 아들, 총 여섯 명으로 맞춘다. 회차 전체를 대표하는 가족 장면으로 사용하며 특정 연도의 전원 합류 사진처럼 설명하지 않는다.

- 공개 이미지 ID와 회차 연결: `ep21-01`, `ep21`, `position.start: true` 유지
- 새 제작 원본: `content/illustration-sources/ep21-01.png`
- 제작 레지스트리: 현재 없는 `ep21-01` 항목을 추가하여 새 원본을 연결한다.
- 대체 설명: ‘수채화로 그린 공장 앞에서 다섯 아들과 들녘을 바라보는 아버지’

**완료 기준:** 아버지 한 명과 아들 다섯 명이 구분된다. 기존 아버지와 네 아들의 모습, 공장·들녘 배경, 수채화 질감을 유지한다. 막내의 외모는 가족 참고자료가 있을 때 그 자료를 따른다. 중앙 기준 16:9 크롭 뒤에도 여섯 인물이 잘리지 않도록 화면 양옆에 여백을 둔다.

### 문단 연결과 제작 기록 수정

삽화 위치는 [삽화 매니페스트](../content/episode-illustrations.json)의 `position.beforeParagraph`가 본문의 전체 문단과 정확히 일치해야 한다. 작업 09에서 16화 639행 문단을 수정하면 `ep16-02`의 연결 문장도 동시에 바꾼다. 같은 문단의 나머지 문장을 포함한 전체 문자열을 수정 후 원고에서 그대로 가져온다.

9화·21화 삽화의 `alt`와 [제작 레지스트리](../content/illustration-sources/regeneration-prompts.json)의 해당 장면 설명·원본 경로·편집 지시·사용하는 해시 기록을 맞춘다. 16화 제작 기록에도 이전 문단이 남아 있다면 바뀐 연결 문구를 반영한다. 과거 제작 이력은 현재 지시와 구분하여 보존한다.

21화 새 레지스트리 항목에는 `id`, `episodeId`, `master`, `sceneHeading`, `sceneExcerpt`, `corrections`, `references`, `prompt`를 기존 항목 형식에 맞춰 등록한다. `references`는 배열로 두고 실제 존재하는 참고 파일 경로·역할·해시를 기록한다. 등록 전에는 선택 생성 명령이 `ep21-01`을 찾을 수 없다. 21화 학업 삽화 `ep21-02`는 입학 문단을 수정하지 않으므로 기존 연결을 유지한다.

편집 전 원본과 교체될 공개 이미지는 별도 보관한다. 기존 공개 ID와 360·720·1280px JPG·WebP 주소는 유지하여 새 이미지로 교체하고, 과거 회차 개편 때 남긴 옛 공개 이미지 주소도 삭제하지 않는다. 12화 정미소 삽화는 이미 함석 지붕으로 보이므로 유지한다. 다른 그림에 주택 지붕이 명확히 묘사되어 있다면 본문과의 일치 여부만 추가 확인한다.

콘텐츠 생성 결과에는 `site/read/`, `site/.vitepress/generated/catalog.json`·`content-manifest.json`, `content/ref_images/catalog.html`이 포함되며 이 결과 파일은 직접 고치지 않는다. `content/ref_images/episode-map.json`은 편집 관리 필드와 자동 갱신 필드를 구분하여 위 지시에 따라 수정한다.

원자료와 과거 제안서는 정정 근거와 편집 이력으로 보존한다. 오래된 제안서의 표현을 현재 원고로 일괄 복사하지 않는다. 음악, 반응 데이터, 사이트 기능 코드는 이번 계획의 직접 수정 대상에 넣지 않는다.

### 이미지 생성과 사이트 검수

9·21화 편집 원본과 레지스트리를 갱신한 뒤 프로젝트 루트에서 아래 명령을 실행했다. 공개 이미지 12개를 생성했고 기존 콘텐츠 테스트 25개와 빌드가 통과했다.

```sh
npm run assets:episodes -- ep09-01 ep21-01
npm test
npm run build
git diff --check
git diff --stat
```

`npm test`와 `npm run build`는 각각 선행 단계에서 콘텐츠 생성을 실행한다. 동일한 생성 명령을 별도로 반복하기보다 생성 결과와 기존 검증을 확인한다. 이번 내용 수정만을 위한 새 테스트나 사이트 기능 전체 테스트는 추가하지 않는다.

### 최종 변경 사항 검수

`git diff`에서 문단 이동과 표현 정정을 구분해 확인한다. 작업 01의 다섯 문단 이동과 작업 07의 한 문단 이동이 삭제로 끝나거나 중복 삽입되지 않았는지 확인한다. 변경된 파일마다 위 적용 범위의 작업과 대응해야 하며, 원자료·음악·반응 데이터의 변경이 섞이지 않아야 한다.

완료 기록에는 본문 13개 항목, 삽화 2개 항목, 연결 문자열 수정, 테스트·빌드 결과를 남긴다. 수정 원고와 삽화·사이트의 검수가 끝나면 계획의 적용 완료로 표시한다. 배포는 별도 요청이 있을 때 수행한다.
