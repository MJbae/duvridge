# 배병희 자서전 대사 문단 분리 전후 비교안

프롤로그부터 외전까지 26개 회차를 확인한 결과, 대사와 발언형 인용을 독립 문단으로 나눌 대상은 원문 문단 기준 18곳이다. 12곳은 빈 줄만 추가하면 되고, 6곳은 인용 구문을 정리해야 대사만 온전히 독립시킬 수 있다. 이 18곳에는 발언 인용 24개가 들어 있다. 내면 독백 1곳도 같은 방식으로 추가 비교한다.

- 대상 원고: [배병희 자서전](/Users/baemanjin/orca/projects/autobio-bae/배병희_자서전.md)
- 비교 기준: 2026년 10월 8일 수정 전 원고 625행. 아래 원문 링크는 적용 후 원고의 해당 문단을 가리킨다.
- 문단 기준: 서술과 대사 사이에 빈 줄을 하나 둔다. 대사 뒤의 행동이나 설명도 별도 문단으로 두며, 서로 다른 발언 인용은 각각 분리한다.
- 문장 보존: 빈 줄만 추가하는 12곳은 모든 글자와 문장부호를 유지한다. 삽입 인용 6곳의 개선안도 따옴표 안의 말은 유지하고, 인용 조사와 문장 연결 및 종결 문장부호만 필요한 범위에서 정리한다.
- 원문을 그대로 두는 선택: 삽입 인용 6곳에는 모든 글자를 보존하면서 대사가 포함된 문장 전체를 독립시키는 대안도 함께 적었다.
- 적용 상태: 2026년 10월 8일 사용자 승인에 따라 대사 분리 18곳과 추가 내면 독백 1곳을 대상 원고에 적용했다. 아래 개선 전은 수정 전 기록이며, 개선 후는 적용한 배치다.

1990년대 말 외환위기로 정미소 형편이 어려웠을 때에도 자식들의 혼사는 온 정성을 다해 치러주었다. 아무리 시절이 각박해도 자식 혼인 잔칫상만큼은 남부럽지 않게 차려주고 싶었던 것이다. 그러나 정작 당신 자신을 위한 상 앞에서는 한없이 박하고 엄격했다. 환갑이나 칠순 잔치를 열어드리겠다는 자식들의 간곡한 청을 한사코 마다했다.

“산 사람이 번잡스럽게 무슨 잔치냐”라며 손사래를 칠 뿐이었다.

- 고함이나 당부가 있었다고만 설명하고 말의 내용이 적혀 있지 않은 곳에는 대사를 새로 만들지 않는다.
- 문서 맨 위 작품 소개의 발언 인용은 본문 대사가 아닌 소개 정보이므로 문단 분리 대상에서 제외한다.
