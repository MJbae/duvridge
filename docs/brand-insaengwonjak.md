# 서비스 이름 개편: 인생원작

기준일: 2026-10-09
작성 방식: Claude Opus 5.5와 GPT-5.6-sol(reasoning max)의 교차 검증
상태: **이름 확정, 상표·도메인 확보 전.** 확보 전까지 이 문서와 새 이름을 공개 저장소에 커밋하지 않는다.

## 요약

| 항목 | 결정 |
|---|---|
| 국내 서비스명 | **인생원작** |
| 고정 장르 설명 | 실화 인생 드라마 |
| 워드마크 | `인생원작.`(Hahmlet 800, 금빛 마침표 = '원작 좌표') |
| 해외명 | **EPORY**(에포리). 해외 진출 때만 쓰고 국내 화면에는 쓰지 않는다. 도메인·상표만 확보한다. |
| 디자인 방향 | 방향 1 「극장」. '극장'은 이름이 아니라 경험이다. |
| 기존 이름 | ToldLife는 정리한다. 같은 업종의 동명 서비스가 있다(4절). |

결정 이유는 세 가지다.

- 두 모델의 최종 평균 점수에서 인생원작과 은막이 8.1점으로 공동 1위였다.
- 인생원작은 이름이 사업 구조를 직접 설명한다. 실존 인물의 삶이 원작소설이 되고, 그 원작이 오디오·영상·각색으로 확장된다. 마케팅 예산이 없는 2인 팀은 이름이 스스로 설명해야 한다.
- 시안의 '원작 n–m화' 표기가 화면마다 브랜드를 다시 떠올리게 한다.

## 1. 진행 과정

| 단계 | 내용 |
|---|---|
| 1. 시안 분석 | 디자인 캔버스의 방향 1 「극장」(영상 시대의 시리즈관)을 기준으로 삼았다. 핵심 구조는 "원작 소설을 축으로 형식이 늘어난다"는 것이다. |
| 2. 독립 리서치 | 리서치 에이전트가 국내외 실화·회고록·콘텐츠 플랫폼 30여 곳의 이름과 정체성을 조사했다. GPT는 웹 검색 약 70회로 후보 12개를 따로 냈다. Opus도 후보 12개를 따로 냈고, 결과를 보기 전에 파일로 고정했다. |
| 3. 1차 교차 채점 | 최종 후보 6개를 같은 기준으로 두 모델이 각자 채점했다. |
| 4. 영어 이름 검토 | 사용자가 제기한 "국내 유사 서비스는 대부분 영어 이름 아닌가"를 검증했다. 서비스 33곳을 분류하고 영문 후보를 스크리닝했다. |
| 5. 확정 | 사용자가 "인생원작 메인, 해외 진출용으로 EPORY 확보"로 결정했다. |
| 6. 반영 | 캔버스에 브랜드 페이지를 추가하고 도메인·상표를 확인했다. |

## 2. 리서치 근거

### 2.1 이름 원칙

1. **성공한 실화 브랜드는 이름에 '실화'를 넣지 않는다.** 고유한 이름을 쓰고, 장르는 태그라인이 알린다.
   - The Moth: "True Stories Told Live"
   - Narratively: "extraordinary true stories"
   - Modern Love는 칼럼에서 팟캐스트, 아마존 드라마, 도쿄·뭄바이판까지 이름 하나로 확장했다.
2. **형식 단어를 넣은 이름은 형식이 늘 때 바뀌었다.**
   - 리디북스 → 리디, Kuku FM → Kuku로 개명했다.
   - 네이버 오디오클립은 종료됐다.
   - Pocket FM은 오디오 연환산 매출 5억 달러를 냈지만 영상(Pocket TV)으로의 확장은 접었다.
3. **국내 '인생극장·사연·실화'는 오염된 단어다.**
   - AI 허구 사연 유튜브가 이 단어들을 많이 쓴다. 한국 기반 상위 11개 채널이 84억 회를 기록했다.
   - '실화'를 이름에 건 방송은 사연 조작으로 다시보기를 삭제한 적이 있다.
   - '인생○○'은 "인생작(최애)"으로 읽히기 쉽다.
4. **'○○극장'은 이미 휴먼다큐를 떠올린다.** KBS 「인간극장」이 2000년부터 쓰고 있다. 그래서 '극장'은 이름이 아니라 경험으로 가져간다.
5. **일본어 위험 단어가 있다.**
   - 実録: 사실과 허구를 섞은 흥미물, 야쿠자 영화 계열
   - 実話: 타블로이드 『週刊実話』
   - 人生劇場: 유명 소설이자 영화 시리즈
6. **비어 있는 자리:** 검증된 실화만 다루는 IP 스튜디오, 그리고 창업주 이야기를 시리즈로 내는 곳이다. 국내 자서전 서비스(시간의 서재, 한권의나, 라이프로그 등)는 모두 "책 한 권"에서 끝난다.

## 4. 영어 이름 검토

**가설 검증 결과: 절반만 맞다.** GPT가 국내 서비스 33곳을 분류했고, Opus의 별도 목록과 결과가 일치했다.

| 분야 | 영문 요소 포함 |
|---|---:|
| OTT(티빙·웨이브·왓챠·라프텔·쿠팡플레이·넷플릭스) | 100% |
| 숏폼 드라마(비글루·숏차·탑릴스·펄스픽·쇼타임) | 100% |
| 웹툰·웹소설 | 87.5% |
| 오디오·오디오북 | 100% |
| **자서전·회고 의뢰 서비스** | **25%(한글 75%)** |

영어 단독 이름을 고르지 않은 이유는 세 가지다.

1. 영문 승자들은 대규모 콘텐츠와 광고로 이름의 의미를 사후 학습시켰다. 2인 팀에는 그 비용이 없다.
2. 매출이 나오는 쪽(창업주·가족의 330만 원대 의뢰)은 한글 이름이 표준인 자서전 카테고리를 따른다.
3. 짧은 영어 이름은 이미 같은 업종에서 쓰이고 있다(직접 확인).

| 영문 후보 | 이미 쓰는 곳 |
|---|---|
| **Told** | **toldstories.co(구술 인터뷰를 본인 목소리가 담긴 책으로 만드는 회고록 서비스)**, 가족 기억 기록 앱·공동 일기 앱 'Told'. 현 이름 ToldLife도 이 서비스와 겹친다 |
| Lived | 'A Life Lived: Audio Memories' 오디오 회고 앱 |
| Storied | storied.com 가족사 플랫폼 |
| Heira · Memora · Kinora | 가족 유산 AI, 기억 기록 앱, 아동 스토리텔링 앱 |
| Filmo · Grain · Matinee | 엔터·사진·영화 트래커 앱 |
| Toliv · Livory · Verita · Truon | 소셜 앱, 독일 부동산 그룹, 헬스케어, 국내 ㈜트루온 |

반대로 한글 로마자 도메인(insaengwonjak, wonjak, eunmak, chammal)은 모두 미등록이었다.

| EPORY | 6.6 | 7.7 |

GPT는 은막을 "eunmak.com 사용 중"이라는 근거로 낮췄다. 그러나 whois·DNS로 직접 확인한 결과 eunmak.com은 미등록이었다. 이 감점은 사실 오류로 판단했다.

**브랜드 구조에 대한 이견**
- GPT는 영문 마스터 `EPORY.`와 국내 호칭 '인생원작'을 동시에 쓰는 하이브리드를 권했다.
- Opus는 반대했다. 한 시장에서 서로 다른 두 단어를 쓰면 이름을 두 번 배워야 한다. 국내 사례(왓챠/WATCHA, 리디/RIDI)는 같은 단어의 표기만 다르다.
- 최종 구조는 시장을 나누는 방식이다. 국내는 인생원작, 해외는 EPORY다. 당근 → Karrot과 같은 방식이다.

### 5.3 말투와 태그라인

**말투 세 가지**
1. 존중하되 영웅으로 꾸미지 않는다.
2. 연도·장소·행동으로 말한다.
3. 짧게 쓴다. 화면에는 조작과 상태만 둔다.

**태그라인**

| 구분 | 문구 |
|---|---|
| 대표 | 살아낸 삶이, 모든 장면의 원작 |
| 보조 | 영화보다 먼저, 인생이 있었다 |
| 의뢰 제작 | 창업주의 삶을, 회사의 원작으로 |

## 6. 디자인 캔버스 반영

[디자인 캔버스](https://claude.ai/artifact/3kqt682wX7dJ81EFhJSDG5)(비공개)에 새 페이지 **「브랜드 · 인생원작」**을 추가했다.

| 보드 | 내용 |
|---|---|
| 브랜드 1 · 아이덴티티 | 워드마크, 앱 아이콘 세 가지, 앱 상단·공유 카드 조합, 색 6개, 글꼴 |
| 브랜드 2 · 이름 체계와 말투 | 이름 체계, 화면 표기 예시, 해외명 EPORY, 말투 세 가지, 태그라인 |
| 브랜드 3 · 홈 적용 | 홈 화면에 새 이름을 얹은 시안. '화면엔 조작과 상태만' 기준으로 머리 문구·설명 줄·재생 시간을 뺐다 |
| 메모 | 결정 사항과 확정 전 확인 항목 |

- 다른 페이지(세 가지 방향, 방향 1 세밀화)의 TOLDLIFE 표기는 그대로 뒀다. 상표 확인 뒤 한 번에 바꾼다.
- 형식 이름과 '원작 n–m화' 표기는 '방향 1 세밀화' 페이지의 최신 기준을 따랐다.

## 7. 도메인 확인 결과

whois로 직접 확인했다(2026-10-09).

| 용도 | 미등록(등록 가능) | 이미 등록됨 |
|---|---|---|
| 인생원작 | `insaengwonjak.com/.kr/.co.kr`, `wonjak.com`, `wonjak.kr/.co.kr`, `인생원작.kr`, `인생원작.com`, `인생원작.한국` | 없음 |
| EPORY | `epory.kr/.co.kr`, `에포리.kr`, `epory.io/.co/.ai/.tv/.jp` | `epory.com`, `epory.net` |

- `wonjak.com`은 6글자 .com이라 QR·광고용으로 가치가 있다.
- `epory.com`과 `epory.net`은 2015년부터 같은 사람이 파킹하고 있다. 등록대행사는 1API GmbH, `epory.com` 만료일은 2027-01-06이다. 중개 사이트(Sedo 등)로 매입을 문의하거나 만료에 맞춰 백오더를 건다.
- `.jp`는 일본 내 주소가 필요하다. 대행 서비스를 이용한다.
- 등록은 결제 계정이 필요해 직접 진행한다. `.kr` 계열은 국내 등록대행자, `.com`·`.io`는 Cloudflare Registrar 등을 쓴다.
