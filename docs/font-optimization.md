# 인생원작 공통 폰트 최적화

포털과 소설·오디오북·영상 리더가 동일한 `/fonts/` 자산을 사용한다. 기존 Hahmlet과 IBM Plex Sans KR의 글자 형태를 유지하고, 수정본의 내부 이름은 ToldLife Serif와 ToldLife UI로 바꿨다. 폰트 생성은 고정된 로컬 원본으로 수행하므로 빌드와 실제 화면에서 Google Fonts에 접속하지 않는다.

제목과 UI의 글자는 작은 공통 서브셋에 담고, 나머지 글자는 원본 전체 문자 범위를 중복 없이 나눠 필요할 때만 읽는다. 새 제목과 UI 문구는 빌드할 때 공통 서브셋에 반영된다. 명조는 400부터 800까지의 가변 굵기 선언 하나를 사용한다. 첫 화면에는 공통 명조와 UI 600 두 파일만 preload한다.

원본 폰트와 라이선스는 `packages/reader-ui/assets/fonts`, 생성기는 `packages/reader-ui/src/fonts/reader-fonts.mjs`에 있다. 생성 자산은 `.deploy/reader-fonts`의 입력 해시별 캐시를 사용한다. 각 리더의 빌드 산출물에 같은 폰트 묶음을 담고, 최종 조립 단계에서 파일의 해시와 묶음의 일치를 검사한 뒤 최상위 `/fonts/`에 한 번만 배치한다.

해시가 붙은 WOFF2와 CSS에는 1년 `immutable` 브라우저 캐시를 적용한다. manifest에는 `no-cache`를 적용하고 HTML의 기존 갱신 정책은 유지한다. 개발·독립 preview 서버도 같은 `/fonts/` 주소와 MIME 타입을 제공한다.

소설과 오디오북 탭은 각 리더의 기존 페이지로 이동한다. 이번 범위는 공통 폰트, 한글 서브셋, 선로딩과 캐시 최적화이며, 작품 상세를 단일 화면으로 통합하는 라우팅 변경은 별도 작업이다.
