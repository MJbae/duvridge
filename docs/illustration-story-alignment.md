# 삽화와 장면 정렬 기록

여러 소재가 함께 들어 있는 6·8·11·13·14·15화의 삽화 표식만 옮겼습니다. 원문 문장과 문단 순서는 유지하고, 그림 파일·삽화 ID·공개 주소·기존 음성·SRT를 보존했습니다. 새 그림 생성이나 녹음은 하지 않았습니다.

## 변경한 여섯 회차

| 회차 | 이전 배치의 문제 | 조정한 본문 위치와 순서 |
| --- | --- | --- |
| 6화 겨울 갯벌의 김 양식 | 김을 마당에서 말리는 가족 그림이 양식 준비·갯벌 채취보다 먼저 나왔습니다. | `ep06-02`의 채취 장면을 유지하고, `ep06-01`을 “갯벌에서 져 온 생김을 마당에 부려놓으면…” 앞으로 옮겼습니다. 채취 → 가족 가공·건조 순서입니다. |

8개 표식의 위치만 변경했습니다. 제목과 시점 줄, 기존 장면 구분도 유지했습니다. 표식 앞뒤의 문구는 위치를 설명하기 위한 기록이며 프로그램이 문구를 대조하지 않습니다.

## 대표 그림과 본문 배치

26개 회차의 기존 `-01` 그림에 `representative: true`를 지정했습니다. 대표 그림은 작품을 요약하는 플레이어 썸네일과 관련 이미지 로딩에 사용합니다. 본문에서는 해당 장면의 표식이 그림의 위치를 결정합니다.

대표 그림이 본문에서 나중에 나오거나 첫 실제 삽화가 `-02`여도 오디오 플레이어의 기존 그림은 유지됩니다. 회차 시작에 삽화를 강제로 붙이지 않으므로 6·8·11·13화는 서두를 먼저 읽고 실제 장면에서 삽화를 봅니다. 재생 버튼·배속·문장 선택·자동 재생 동작은 바꾸지 않았습니다.

실제 매니페스트는 회차마다 대표 그림을 하나만 지정합니다. 위치를 직접 편집하는 `position` 필드는 없으며, 본문 순서와 시작 여부는 표식에서 계산합니다. 대표 지정이 없는 작은 테스트 자료는 첫 표식을 대표로 삼습니다.

## 보존 검증

삽화 표식을 제거한 원고를 변경 전과 비교해 모든 문장·문단의 순서와 바이트가 같음을 확인합니다. 수정 대상이 아닌 나머지 20개 회차는 렌더링 HTML도 변경 전과 비교합니다. 공개 그림·그림 원본·기존 낭독 MP3·SRT의 해시를 비교해 파일 내용을 보존합니다.

일반 편집 방법과 검증 명령은 [삽화 편집 안내](illustration-authoring.md)를 따릅니다. 앞으로는 대표 그림의 요약 역할과 본문 삽화의 장면 역할을 따로 확인하고, 장면이 달라질 때 해당 표식만 옮깁니다.
