개선 방향

회차의 시대·장소를 정본 원고에서 한 번 작성하고 소설 화면, 오디오북 회차 화면, 낭독 도입이 함께 사용합니다. 소설에서는 첫 삽화 아래, 첫 문단 위에 안내를 표시합니다. 본문에서는 연도만 덧붙이는 도입을 줄이고 사건의 흐름으로 시대를 드러냅니다. 오디오북은 기존 시안을 유지하며, 목차·회차 목록의 화면과 데이터는 이번 수정 범위에서 제외합니다.

확인한 원인

  • 원고 파서는 *1950년대 · 안면도 중장리*를 time으로 분리하고 본문에서 제거합니다. 현재 이 줄은 모든 회차에 필수입니다.
  • 소설 페이지 생성은 분리한 time을 본문에 다시 넣지 않아, 정본에 있는 안내가 읽기 화면에서 빠집니다.
  • 오디오북 대본 생성은 같은 줄을 dateline으로 한 번 읽습니다. “1950년, 6·25 전쟁이 터졌다.”처럼 이어지는 본문에도 연도가 있으면 중복됩니다.
  • 회차 목록은 회차 번호와 제목을 사용합니다. 사용자 지시에 따라 현재 목록과 목차의 구성·표시·데이터를 수정하지 않습니다.

반영 순서

  1. 정본 원고의 편집 원칙을 맞춥니다. 각 회차 제목 다음의 기존 시점 줄을 활용합니다. “1950년,”처럼 배경 안내와 겹치는 도입만 덜어내고, “전쟁이 지나간 뒤에도” 같은 자연스러운 맥락은 유지합니다. 사건의 선후 관계에 필요한 연도는 삭제하기 전에 다른 표현으로도 뜻이 분명한지 확인합니다. 연령, 기간, 금액, “6·25” 같은 사건명은 유지합니다.
  2. 배경 안내를 선택 사항으로 처리합니다. 안내 줄이 없는 회차는 time을 비워 두고 원문 전체를 본문으로 처리합니다. 시대·장소 형식의 터전 제목도 없는 작품을 수용하되, 기존 작품의 구조와 주소는 계속 지원합니다. 연도·장소를 따로 복제해 book.json 등에 저술하지 않습니다.
  3. 소설의 안내를 첫 삽화 아래에 표시합니다. 소설은 첫 삽화 → 시대·장소 한 줄 → 첫 문단 순서입니다. 첫 삽화가 없는 회차는 첫 문단 앞에 안내를 둡니다. 오디오북은 승인된 시안대로 회차 제목 아래에 같은 한 줄을 둡니다. 안내가 없으면 줄과 그 여백을 렌더링하지 않습니다. 목차·회차 목록의 화면·스타일·데이터는 수정하지 않으며, 목록과 다음 화 카드에 안내를 추가하지 않습니다.
  4. 낭독은 사용자가 선택한 도입 1회를 따릅니다. 회차 제목 → 시대·장소 한 줄 → 짧은 쉼 → 본문 순서입니다. 도입을 읽는 동안에는 상단 한 줄이 안내와 자막 역할을 함께 맡고, 아래 낭독 문장 영역에는 본문 문장만 표시합니다. 본문 대본에도 안내 줄을 다시 섞지 않습니다. 이 표시 구분 때문에 낭독 큐의 인덱스나 타이밍을 바꾸지 않습니다. 재생 위치 이동이나 다시 듣기는 기존 방식대로 해당 음성 위치를 재생합니다.
  5. 웹 반영과 음성 제작을 나눠 검증합니다. 웹 빌드는 녹음·SRT·승인 클립을 생성하거나 수정하지 않습니다. 본문에서 덜어낸 연도를 실제 MP3에서도 없애는 작업은 별도 요청된 음성 제작 단계에서 적용합니다. 기존 오디오의 텍스트 차이는 원고 편집이나 웹 빌드를 막는 조건으로 삼지 않습니다.

완료 기준

  • 같은 회차의 소설·오디오북에서 배경 안내의 문구가 같고, 회차 본문 영역에 한 번 표시됩니다. 소설의 표시 위치는 첫 삽화 아래, 첫 문단 위입니다.
  • 안내를 사용하지 않는 작품도 목록·읽기·듣기 화면과 콘텐츠 빌드가 정상적으로 동작합니다.
  • 목차·회차 목록은 현재 화면과 데이터 그대로 유지하며, 목록과 다음 화 카드에 안내 문구를 추가하지 않습니다.
  • 정본과 생성된 본문을 비교하고, 영향받는 워크스페이스의 테스트·빌드·타입 검사와 UI 브라우저 검증을 수행합니다. 실제 음성 반영 시에는 도입이 한 번인지 듣고 확인하고 파일·타이밍 검사를 유지합니다.

이 제안에서는 앱 코드와 정본 원고를 수정하지 않았습니다. 화면의 본문은 3화 첫 문장에서 “1950년,”만 덜어낸 최소 수정 예시이며, 화면의 재생 위치는 설명용입니다. 이 HTML과 PNG 시안을 별도 워킹 트리에서 작성하고 검토하여 메인에 반영합니다.
